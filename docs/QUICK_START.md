# 同频 · 开始使用

相隔时区，也能同频。系统保留当地时区，同频独立显示中国时间与日期。

## 1. 解压并打开

从 https://github.com/songchao-bstvc/Tongpin-ChinaTime/releases/latest 下载 Windows x64 ZIP，完整解压到固定文件夹，双击 `ChinaTime.exe`。

推荐 Windows 11 x64，使用系统 .NET Framework 4.8 或更高版本。无需管理员权限。当前版本未进行商业代码签名；可在发行页核对 SHA-256。程序不修改 Windows 时区。

## 2. 设置登录后自动显示

点击时钟打开日历 →「外观与设置」→「通用」→ 勾选「登录 Windows 后自动显示中国时钟」→「保存设置」。登录启动会在进入 Windows 桌面后显示时钟。

移动解压目录或升级后，请重新设置启动项。时钟出现后默认只显示时间、日期和星期；没有“中国”前缀，秒数默认关闭。

## 3. 新增备忘

在日历中选择一天 →「＋ 备忘」→ 填写标题、正文与中国日期/时间 → 按需要开启提醒与重复 → 保存。

例如：为中国时间今晚 20:00 添加“和家人视频”。编辑窗会显示本地时间换算。窗口关闭后时钟和提醒继续运行；程序完全退出后提醒停止。

重复支持单次、每天、周一至周五、每周、每月同日、每年同日（公历）。不存在的日期跳过。周一至周五不等于法定工作日；农历生日按年重复尚未实现。

收到提醒可选择「已完成」「稍后 10 分钟」「知道了」。日历还提供「未来 7 天」、全文搜索和回收站恢复。

## 4. 外观、位置与实时卡片

右击时钟 →「外观、位置与实时信息」，或日历 →「外观与设置」。改动即时预览，保存后记住，取消可还原。

- 外观：跟随 Windows / 浅色 / 深色，磨砂玻璃 / 实色，真透明时钟 / 柔和衬底；可显示秒数、调整大小和文字清晰度。
- 位置：任务栏、左下/右下/上方/居中等桌面预设，自定义拖动与显示器选择。默认锁定，按住 Ctrl 仍可拖动。
- 实时信息：独立实时卡片，可选本地时间与时差、农历、提醒倒计时、纪念日/见面倒数、今日进度。默认关闭；私人标题默认隐藏。
- 任务栏副行：可勾选农历、本地时间、提醒倒计时、纪念日；选中后约每 8 秒轮换。
- 通用：登录启动、提示音、全屏隐藏、提醒隐私和纪念日期。

复杂壁纸可选柔和衬底；系统关闭透明或高对比度时会回退。显示器布局或第三方任务栏工具造成遮挡时，改用桌面位置。

## 5. 备份、升级与停用

备忘与设置位于 `%LOCALAPPDATA%\TongpinChinaTime`，与解压目录分开。

换电脑、重装系统或升级前：日历 →「导出加密备份」，设置至少 8 位密码，分别保管密码与备份文件。新环境可通过「恢复备份」导入。密码遗失无法恢复。

升级：先导出备份 → 退出旧版 → 解压新版并运行 → 检查备忘 → 重新保存登录启动设置。不要同时启动多个版本来编辑同一份数据。

停用：取消登录启动 → 保存 → 右击时钟/托盘 →「退出同频」。需要卸载时再删除程序文件夹；私人数据保留以便恢复。要清理数据，请先导出并确认备份可用。

## 快捷键与提醒边界

| 快捷键 | 功能 |
| --- | --- |
| Ctrl + N | 日历中新建备忘 |
| Ctrl + F | 日历中搜索 |
| Esc | 收起日历 |
| Ctrl + 拖动时钟 | 临时解除位置锁定并移动 |

提醒约每 10 秒扫描一次；关机、休眠、锁屏、退出期间不会弹出，也不唤醒电脑。恢复运行后处理遗漏，重复提醒合并最近 7 天内的最近一次。时钟依赖 Windows 自身 UTC 准确性，不提供在线授时。

法定休班数据内置到 2026 年，后续年份需更新。问题反馈：https://github.com/songchao-bstvc/Tongpin-ChinaTime/issues
