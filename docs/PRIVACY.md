# 隐私与备份

同频在本地运行，不设账号、不连接云同步、不上传备忘，也不包含广告或遥测。源码可检查。GitHub 项目页、下载站及 README 在线徽章由对应服务提供，不属于应用运行时联网。

## 数据在哪里

`%LOCALAPPDATA%\TongpinChinaTime`：

- `private-memos.bin`：Windows DPAPI 当前用户加密的备忘、提醒处理记录与偏好。
- `private-memos.bin.previous`：上次保存版本。
- `backups/memos-YYYY-MM-DD.bin`：每个中国日期第一次修改前的自动备份。
- `app.log`：启动与诊断日志；常规提醒日志记录 ID，不记录标题正文。提交问题前仍应自行检查日志，不要上传备忘文件。

DPAPI 以当前 Windows 账户为保护边界。同一账户下的其他程序仍可能访问数据。加密并不防止已登录用户、桌面截图或恶意软件读取屏幕内容。自动备份依赖当前账户，不能作为换电脑/重装后的唯一恢复手段。

## 换电脑与重装系统

使用日历中的「导出加密备份」，密码至少 8 字符。格式采用 PBKDF2-SHA256（150000 次）派生密钥、AES-256-CBC 加密及 HMAC-SHA256 完整性校验；导入前验证密码与完整性。尚未经过独立第三方安全审计。

分别保管文件和密码；密码遗失无法找回。更换电脑前，建议先在独立测试配置中确认能恢复。

「恢复备份」支持密码备份 `.cstbackup`，也支持当前账户能解密的 `.bin` / `.previous`。恢复采取合并，同一 ID 保留较新记录，不删除其他已有记录。

## 本机损坏恢复

如果程序因主数据损坏无法打开，先退出程序。保留损坏文件的副本，将其改名；将 `.previous` 或每日备份中的确认版本复制为 `private-memos.bin` 后重启。不要删除唯一副本。

## 发布问题时

公开 Issue 不要附私人备忘、备份文件、密码或未检查的日志。可提供 Windows 版本、缩放比例、屏幕布局及去除私人内容后的界面截图。
